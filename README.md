# 알고리즘2 중간고사 학습 자료 · GitHub Pages 배포본

## 포함 자료
- HTML 학습실: 강의별 설명·코드 예제·그림·모션·연습·브라우저 내 진도/답안 저장
- 시험 당일 압축요약: HTML/PDF
- 모의고사1–5회: HTML/PDF 및 별도 정답·해설

원본 강의 PDF(알고리즘1 참고 PDF 포함), 원본 기출·기출 재구성/해설, 녹음·전사문, 원본 과제 파일, 분석/검사/제작 스크립트는 포함하지 않습니다. 설명 안의 강의명·쪽수는 출처 표시이며 원본 파일 링크가 아닙니다. 코드 예제와 해설은 학습실 본문에 유지됩니다.

## GitHub Pages에 올리기
1. 이 폴더의 **내용 전체**를 전용 저장소 루트에 넣습니다. 상위 공부 폴더 전체를 올리지 않습니다.
2. `.nojekyll` 파일과 폴더 구조·파일명 대소문자를 유지합니다.
3. 저장소 Settings → Pages → Deploy from a branch에서 업로드한 브랜치와 `/(root)`를 선택합니다.
4. 발급된 Pages 주소로 접속하면 학습실이 열립니다. `/docs`를 사용할 경우에는 이 폴더의 내용을 저장소 `/docs`에 두고 Pages에서 `/docs`를 선택합니다.

HTML/CSS/JavaScript를 그대로 제공하므로 별도 빌드나 서버 프로그램은 필요 없습니다. 모바일 브라우저에서도 같은 주소를 사용합니다. localStorage 진도·답안은 해당 브라우저에만 저장되며 기기 간 동기화되지 않습니다. 파일 URL에서 저장한 진도는 새 Pages 주소로 자동 이전되지 않습니다.
