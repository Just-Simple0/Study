출제 구성과 범위

2024 원본의 시험 전체를 구성하는 유형을 기준으로 새 문제를 작성했다. 원본의 개별 개념을 특정 유형에 고정하지 않았다. 회차별 난도는 제작상의 목표이며 실제 응시자 자료로 보정한 수치는 아니다.

형식

대문항 / 배점 17개 / 100점 17개 / 100점

시간 현재 공지 60분 각 회차 60분 연습

긴 독립 프로그램 전체를 백지에서 작성하거나 T/F·객관식 위주로 구성하지 않았다. 코드의 앞뒤 문맥·변수·자료구조·보조 함수의 의미를 함께 제공한다.

난도 조절

  • 1회 쉬움: 작은 숫자·3행 삼각형·3개 물건·3단계 탐색 트리, 짧은 코드와 직접적인 상태 정의를 사용했다. 유형 수와 배점을 줄이지 않고 추적 단계와 조합 수를 줄였다.
  • 2회 유사: 중첩 QUADTREE, 두 가지 POLY 구현, k번째 LIS의 분기 수, 6개 물건의 배낭 조합을 혼합했다. 필요한 규칙은 문제에 명시했다.
  • 3회 유사: LIS 길이·개수·사전순 복원을 연결하고, 재귀 Huffman의 읽기 위치와 제자리 DP 갱신 방향을 묻는다. 복합 코드가 있는 대신 예제 수열과 트리를 작게 하고 대부분의 골격을 제공했다.

기출의 같은 개념을 같은 문항 유형으로 복사하지 않았다. 예를 들어 Huffman은 트리 계산(1회)→반복 디코더 빈칸(2회)→재귀 디코더·비트 추적(3회), LIS는 choices 표(1회)→DP 빈칸·k번째 표(2회)→tails 추적·k번째 코드(3회), 배낭은 메모·복원 코드(1회)→분할 조건 비교(2·3회)로 바뀐다.

범위와 출제 예고

범위 기준은 올해 공지와 Lec.00–06이다. CLOCKSYNC 상태 공간 트리, QUADTREE 상하 반전, Huffman 인코딩·디코딩 예고를 세 회차에 포함했다. Master Theorem도 코드에서 재귀식을 읽는 유형으로 포함했다. 개별 유형의 실제 출제를 보장하는 자료는 아니다.

QUADTREE 압축·해제는 뒤집기를 이해하기 위한 표현 규칙만 사용하고, 두 구현을 독립 출제 확정 항목으로 만들지 않았다. 원본 기출에 있더라도 올해 직접 대응이 확인되지 않은 행렬 회전 코드와 TSP 하한 가지치기는 넣지 않았다. 알고리즘1의 LCS·Floyd 등도 추가하지 않았다.

세 회차가 모든 PDF 문장·보충 구현을 한 번씩 시험한다는 뜻은 아니다. 다음 표에 실제 출제한 범위를 남겼으며, 회차에 없는 세부 내용은 학습실에서 복습한다.

채점 시 허용하는 답

  • 문장·용어는 한국어 또는 영어 모두 허용한다. 핵심 의미가 같으면 표현 차이를 감점하지 않는다.
  • 동작과 조건이 같은 코드·식은 인정한다. Python 문법 자체보다 알고리즘 의미를 본다.
  • 전체 호출 수의 지수·합 기호 표현을 허용한 문항은 십진수 전개를 요구하지 않는다.
  • 경로·물건 목록·직사각형 구간을 묻는 문항은 요구한 인덱스 또는 값의 구분을 따른다.
  • 소수 근삿값 대신 정확한 분수로 답해도 된다. 유효한 다른 최적해가 있다면 그 해도 인정한다.

정답 검사

실제 코드 빈칸 24문항에 해답을 삽입해 실행했다. 작은 입력의 완전탐색·부분집합 열거·수열 열거·픽셀 변환 등을 별도 기준으로 사용했다. 개념 단답은 현재 강의 범위·문제의 전제와 대조했다. 자동 검사는 문항의 실제 체감 난도나 모든 자연어 정답의 유일성을 증명하지 않는다.
